## Blog Writing Guide

Match the tone of https://nvoxland.github.io/bundlebase/blog:

- First person, conversational ("I pushed out...", "I'm planning...")
- Candid about limitations -- don't oversell or hedge
- Short paragraphs, no filler
- Code examples early and often
- Em-dashes as `--` not unicode
- Release post structure: one-line opener, install command, features with code, honest status, brief roadmap, GitHub link
- No corporate voice, no emojis, no exclamation marks
